# Changelog

## 1.0.3 — 2026-10-09

通过 Git `#main` 安装的项目可在 Package Manager 中点击 Update；固定本次版本使用 `#v1.0.3`。已导入的示例需要重新导入，详见[安装与迁移指南](Documentation~/Upgrading.md)。

- 修复示例场景生成器、截图工具和场景回归中的 `FindObjectOfType` 弃用警告：Unity 2022.2 及以上使用 `FindFirstObjectByType`，旧版 Unity 保留原 API。
- 场景查找保持原有的首个活动对象语义，通过编译条件选择 API，不增加运行时版本判断或额外分配；运行库 API 保持不变。

## 1.0.2 — 2026-10-09

通过 Git `#main` 安装的项目可在 Package Manager 中点击 Update；固定本次版本使用 `#v1.0.2`。升级前请查看[安装与迁移指南](Documentation~/Upgrading.md)，新版示例需重新导入。

- 增加 CallbackTree 回调折叠示例：OnItemRender 直接渲染三层节点，ViewFactory 缓存组件和监听，配套回收／销毁回调、未读排序、祖先链定位、独立场景生成器和交互回归；保留现有三个 Adapter 示例。
- 破坏性清理：移除未被运行库或示例使用的公开 GameObjectPool 类型及其独立测试。VirtualScrollView 继续使用内部按模板分桶的视图池；外部直接使用该工具类的代码需要迁移到自己的对象池。
- 折叠排序缓存比较委托并复用排序缓冲，保留稳定排序与异常清理语义，避免为每组创建内部排序对象。
- 分组和树折叠控制器提供可选的 ExpandableListAdapter、TreeListAdapter 接入，集中复用数据访问、显示、尺寸与清理逻辑，同时保留函数与 OnItemRender 回调入口。两种入口在构造时选定，显示配置互斥，共用控制器的底层接口实现，无额外 Bridge。三个折叠示例使用 Adapter 并补充中文注释，增加双入口行为、共享实例清理及预热 GC 回归。
- 折叠控制器支持 Submit 后订阅渲染：未订阅时不创建空白项，列表启用时订阅增删立即刷新、最后退订回收可见项并保留池，禁用时延至恢复启用后处理；导航临时测量也会触发渲染回调，不代表曝光或阅读。Dispose 完成清理后释放所持有的委托。
- 增加独立 BusinessSortedTree 业务排序示例：三个状态独立开关、四层状态汇总、红点／解锁／未读／ID 优先级、根分组排序前后对照与点击回归。
- 增加多层 TreeListController：迭代树遍历、同级比较器、后代展开状态保持、整条祖先链自动定位、跨父节点移动与可见祖先锚点回退；提供四层 TreeList 场景和深树／分配回归。
- 增加通用一级分组折叠控制器：稳定 Key、一次 Submit 更新、可选业务比较器、展开状态保持、隐藏子项定位和多模板动态尺寸。
- 增加 ApplyData 序列更新入口，按新旧行映射保留实例与滚动锚点，确保旧绑定先解绑再切换数据；提供折叠示例、使用文档和分配回归。
- 缓存可见范围，同范围滚动跳过 item 遍历；稳定跨界仅处理进出项，尺寸、布局或刷新变化时自动回退到完整更新。
- 回收池按 prefab 分组并通过索引交换删除；复用单次获取中已选的模板，减少查找和业务回调。
- 复用稳定的尾部校正与即时跳转解析结果，减少相邻布局检查和重复几何读取，完善异常后的实例回收。
- 缓存尺寸索引查找起始位，网格稳定计数改为 O(1)，跳过无变化的布局写入。
- 直接网格示例增加范围缓存，奖励示例减少无变化的属性写入和缓动计算。
- 增加分段 Profiler 标记，补充[性能优化说明](Documentation~/Performance.md)。

## 1.0.1 — 2026-10-07

- 最低支持版本调整为 Unity 2021.3 LTS，兼容 Unity 6。
- 十个示例在启动时根据输入后端配置 EventSystem，支持旧 Input Manager、新 Input System 和 Both；修复仅启用 Input System 时读取 UnityEngine.Input 的异常。
- Input System 保持可选依赖，提供示例用的链接保留配置，避免播放器构建裁剪动态加载的输入模块。
- 场景生成器同步使用自动输入配置，并兼容旧版 Unity 的 Arial 和新版 Unity 的 LegacyRuntime 内置字体。
- 补充安装升级与重新导入示例的说明。

## 1.0.0 — 2026-10-07

首次公开发布 ZRList。

- 提供独立的 `com.zr.list` UPM 包和 `ZRList.Runtime` 程序集。
- 支持横竖虚拟列表、多预制体复用、动态尺寸、批量更新、尾部追加和动画定位。
- 提供按行虚拟化网格、可见项查询、异步绑定校验与资源生命周期接口。
- 支持双向嵌套滚动、主轴手势分发、惯性和弹性边界。
- 附带十个可导入的示例、编辑器生成器与完整使用说明。
- 使用 Apache-2.0 许可证。
